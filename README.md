# Employee Management System

## Description
A Python OOP project that manages employees using Object-Oriented Programming concepts.

## OOP Concepts Used
- Class and Object
- Inheritance
- Encapsulation
- Abstraction
- Polymorphism
- Method Overriding

## Features
- Display employee details
- Display salary
- Different roles such as Developer and Manager
- Employee work activities

## Technologies
- Python
- Object-Oriented Programming
